# decision-record

組織の誰かが決めたことと、「誰が決める・承認するか」という決め方を、あとから探せる形で残す。記録（DR）は記録のリポジトリ（このリポジトリ。ほかのリポジトリからはこのフォルダーの `STORE` に書いたもの）の `records/` に、1 件 1 ファイルの Markdown で置く。答えはユーザーの言葉で返す。

コードのリポジトリでは、ADR キット（`adr/`）の `adr-guard` がこの記録を読んで変更を確かめ、`decision-log` が過去の変更を Decision logs に起こす。

## モード

渡されたものと頼まれ方から選ぶ。使う人にモード名を覚えさせない。

| モード | こんなとき | 返すもの |
|---|---|---|
| 聞く | 「なんでこうなってる？」「誰の承認で決まる？」「これ自分で決めていい？」 | 記録だけを根拠にした答えと、使った記録の番号（DR-42 など）。なければ「記録なし」と、誰に聞けばよさそうか |
| 拾う | スレッド・議事録・PR・決めた人の返事を渡された | DR の下書き（`entry: auto`、元になかった項目つき） |
| 書く | これから重い判断を決めたい。設計の判断を残したい | 問いかけと、提案中の DR |
| 決め直す | 過去の DR を変えたい | 新しい DR と、古い DR への「終了」の追記 |
| 決定にする | Decision log の変更を、決定として残したい | 新しい DR と、Decision log への一行の追記 |
| 追記する | 見直しの時期が来た、結果が出た、提案中の DR が決まった、探し方を直したい | 古い DR への一行の追記 |

「聞く」で記録がなければ、決めた人に聞いて、その返事を「拾う」に回すよう勧める。必要とされたときに残すので、使われる決定だけがたまる。

## 読むもの

モードを決めたら、その手順だけを読む。

| 読むとき | 文書 |
|---|---|
| 拾う・書く（重さ、探し方の項目を含む） | [references/capture-and-write.md](references/capture-and-write.md) |
| 決め直す・決定にする・追記する | [references/amend.md](references/amend.md) |
| 記録を読む・書く（置き場所、番号、`records.py`） | [references/store.md](references/store.md) |
| 本文と記録データ（フロントマター）を書く | [references/record-format.md](references/record-format.md) |

## 入り方

- `explicit`：人が意図して追加した。そのまま根拠にしてよい。
- `auto`：仕組みや AI が拾った。元の場所と一緒に「拾った内容」として扱う。
- 人が `auto` の記録を直すか採用すると `explicit` に変わる。自分の判断では変えない。

## 聞く

記録だけを根拠に答え、使った記録の番号（DR-42 など）を必ず示す。「誰の承認で決まる？」には `kind: flow` を優先して使う。「これ自分で決めていい？」には、似た領域・影響範囲の判断を過去にどの役割が決め（`decided_by`）、どの役割が承認してきたか（`approved_by`）を示し、最後の判断は本人と組織長に委ねる。`auto` の記録を使うときは「拾った記録では」と添え、崩れた前提がある記録は「見直しが必要」と添える。記録がなければ、`config.yaml` の roles か担当チームから聞く相手を挙げ、分からなければ質問者に「この領域の持ち主は誰か」を聞く。

## 状態

状態は3つだけ。縛るのは「有効」だけ。

| 状態 | 表し方 |
|---|---|
| 提案中 | 「終了」の追記がなく、`status: proposed`（「決まった」の追記がない） |
| 有効 | 「終了」の追記がなく、`status: accepted`、または「決まった」の追記がある |
| 終了 | 「**終了**」の追記がある。置き換えたなら一行目に「置き換え」、やめたなら理由 |

Decision logs の記録には状態がない。過去の観察で、何も縛らない。

## 守ること

- 状態は元の事実を写すだけ。自分の判断で `accepted` や `explicit` にしない。
- 「記録しないで」と言われたものは、下書きも残さない。
- 人事（評価・異動・処遇・個人の情報）に関わる判断は取り込まない。「限定の場所に手で残してください」と伝える。DM は本人が渡したときだけ扱う。
- 記録を個人の評価やランキングに使わない。外れたときは、人ではなく決め方と前提を振り返る。
- 中身の良し悪しは判断しない。問いを投げるだけ。
