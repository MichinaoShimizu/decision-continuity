# decision-records

組織の意思決定を、あとから探せる形で残す場所と、そのためのスキル。

- **記録**：このリポジトリの Discussions
  - Decisions：決めたこと
  - Decision flows：誰が決める・承認するかの決め方
  - Q&A：「なんでこうなってる？」の質問。答えが付いたら記録にする
- **スキル**：`decision-record`（`.claude/skills/` と `.kiro/skills/`）
- **設定**：`config.yaml`（役割の一覧、拾ってよいチャンネルなど）
- **評価ケース**：`evals/cases.yaml`

## 使い方

このリポジトリを開いて、Claude Code か Kiro に話しかけます。

- 「なんでタイムアウト5秒なの？」
- 「部署をまたぐ変更って誰が承認すれば決まる？」
- 「これ自分で決めていい？」
- 「このスレッドから記録を作って」

Discussions のフォームから、直接書くこともできます。

## 置かないもの

人事（評価・異動・処遇・個人の情報）に関わる判断は、ここに置きません。
